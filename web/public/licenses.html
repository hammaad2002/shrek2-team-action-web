This site

The page, the installer, the in-browser translator and the engine are open source: __REPO_URL__ (see its LICENSE file). The site contains no part of Shrek 2 Team Action: players unpack their own disc image in their browser, and the game's program is translated there.

FFmpeg (libavcodec, libavutil) — LGPL 2.1 or later

The engine (engine/shrek2_player.wasm) is statically linked with a minimal build of FFmpeg 7.1.1 containing only the Bink video and Bink audio decoders. FFmpeg is licensed under the GNU Lesser General Public License, version 2.1 or later.

  • Unmodified source: ffmpeg.org/releases/ffmpeg-7.1.1.tar.xz
  • Build configuration: tools/build-ffmpeg-web.sh in this site's source repository.
  • To use a modified FFmpeg, rebuild the engine from the repository with tools/build-web.sh (instructions in its README); the whole engine source is available, so it can be relinked.

iced-x86 — MIT

The in-browser translator decodes x86 instructions with iced (iced-x86 1.21.0), Copyright (C) 2018-present iced project and contributors, under the MIT license.

Emscripten — MIT

The engine is compiled with Emscripten 6.0.12, whose runtime code and system libraries are included in it: Emscripten's own code (MIT), musl libc (MIT), and LLVM's libc++, libc++abi and compiler-rt (Apache License 2.0 with LLVM Exceptions).

dlmalloc — MIT-0

Memory allocator by Doug Lea, released to the public domain and re-licensed under MIT-0.

Vite — MIT

The page is built with Vite; its small module-loading helper is part of the page's script.
